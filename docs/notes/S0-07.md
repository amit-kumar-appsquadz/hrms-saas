# S0-07 — openapi.yaml skeleton (auth, roles, employees)

What changed: Added `openapi.yaml` (OpenAPI 3.1) as the single contract. Covers auth (login, MFA verify, refresh, logout, me), roles CRUD, and employees (list/create/get/update). Tenant-agnostic paths with the tenant resolved from the subdomain (server variable), Sanctum bearer auth, a consistent `Error`/`ValidationErrorBody` shape, a standard `PaginatedEnvelope` on every list, and sensitive-field handling (PAN/bank are `writeOnly` on input, returned only masked/last-4) per ADR-006.

Risks: this is a skeleton — schemas will grow as modules land; must not drift from the ERD. Sprint 1 application code must not start until this is reviewed (your decision 10).

How to verify: open `openapi.yaml` in an OpenAPI viewer/linter; confirm paths are tenant-agnostic, error/pagination shapes are consistent, and no plaintext PAN/bank is ever returned. Review gate: "You review".
