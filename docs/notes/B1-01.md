# B1-01 — `tenants` table + lifecycle status column (ADR-008)

Branch: `agent/B1-01` · Owner: Backend · Depends on: B1-00

## What changed
Created the platform-owned `tenants` registry and its model, per ADR-008 and
ADR-001 (dedicated-DB seam) / ADR-007 (platform plane).

- `backend/database/migrations/0001_01_01_000100_create_tenants_table.php`
  - Columns: `id`, `subdomain` (unique), `name`, `status` (enum, indexed,
    default `provisioning`), `plan`, `region`, `primary_contact`,
    `contact_email`, `trial_ends_at`, `suspended_at`, `suspended_reason`,
    `offboarded_at`, `db_connection` (nullable — ADR-001 seam), timestamps.
  - `UNIQUE(subdomain)` and `INDEX(status)` present.
  - Status enum matches ADR-008 **exactly**: `provisioning | trial | active |
    suspended | inactive`. No `pending` (explicitly rejected synonym).
  - **No `tenant_id`** — this is a platform-owned table.
- `backend/app/Models/Tenant.php`
  - Plain Eloquent `Model`; does **NOT** use `BelongsToTenant` / any tenant
    global scope (would be a bootstrap paradox — the resolver reads this table).
  - `Tenant::STATUSES` is the model-layer source of truth for the ADR-008 set;
    `LOGIN_ALLOWED_STATUSES` = `[trial, active]`; `canLogin()` helper for the
    resolver (B1-05).
  - **Subdomain immutability** enforced in `booted()` via an `updating` hook that
    throws if `subdomain` is dirty (ADR-008 — no post-creation rename in Phase 1).
    `subdomain` stays in `$fillable` so it can be set on create.
- `backend/database/factories/TenantFactory.php`
  - Default `provisioning`; states `trial()`, `active()`, `suspended()`,
    `inactive()`.
- `backend/tests/Feature/Platform/TenantSchemaTest.php`
  - Schema (columns/unique/index), enum-values exactness (incl. no `pending`),
    platform-owned (no `tenant_id`, no scope/trait), subdomain immutability
    (throws + not persisted), other-field mutability, `canLogin()` by status.

## Contract / ADR alignment (no drift)
- `openapi.yaml` `TenantStatus` enum = `[provisioning, trial, active, suspended,
  inactive]` — matches the migration/model exactly.
- `PlatformTenant` schema field names (`subdomain`, `status`, `plan`,
  `primary_contact`, `contact_email`, `region`, `trial_ends_at`, `name`,
  `created_at`) all map to columns created here.
- No ADR or `openapi.yaml` file modified. No architectural change.

## Risks / notes
- On sqlite (tests) `enum` degrades to a string/check column — there is no native
  ENUM; the DB will not reject an out-of-set value the way MySQL does. The model
  (`Tenant::STATUSES`) and the lifecycle service (B1-04) remain the enforcement
  authority. Acceptable: steering mandates sqlite `:memory:` for tests and MySQL
  in prod; the enum constraint is real on MySQL.
- Subdomain immutability is a model-layer guard (`updating` hook). A raw
  `DB::table('tenants')->update(...)` bypasses it — by design Eloquent-only. If a
  DB-level trigger is later wanted, that is a separate decision.
- `db_connection` is a nullable seam only; no dedicated-DB routing is wired in B1.
