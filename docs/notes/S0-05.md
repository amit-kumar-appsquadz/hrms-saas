# S0-05 — ADR-005 Payroll orchestration (Step Functions)

What changed: Added `docs/adr/ADR-005-payroll-orchestration.md`. Step Functions orchestrates payroll runs (prepare -> fan-out over employees -> aggregate -> generate outputs -> human review/lock gate); orchestration is strictly separated from calculation via a `PayrollCalculator` interface. No statutory math is invented here. Runs are idempotent/restartable; calculation PRs are `needs-expert`.

Risks: fan-out concurrency must be bounded to protect the shared cluster/latency budget; the human review/lock gate is essential so no un-verified run is treated as final.

How to verify: read the ADR; confirm the separation-of-concerns and the review gate. Open questions: Standard vs Express workflows, Map batch size, snapshot storage. All money logic deferred to Sprints 11-16 with expert verification.
