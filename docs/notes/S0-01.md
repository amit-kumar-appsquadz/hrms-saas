# S0-01 — ADR-001 Tenancy model

What changed: Added `docs/adr/ADR-001-tenancy-model.md`. Decided shared-DB + `tenant_id` as the Phase-1 default for the mid-market segment, with `BelongsToTenant` global scope, `tenant_id`-first composite indexes, subdomain tenant resolution, tenant-prefixed cache keys, and a `TenantConnectionResolver` seam so dedicated-DB-per-tenant can be added later for enterprise. Dedicated DB is NOT implemented in Phase 1.

Risks: a global-scope miss is a cross-tenant leak; noisy-neighbor on the shared cluster. Both are mitigated (mandatory isolation tests S1-06/S1-07, per-tenant rate limiting S6-04, and the seam to move heavy tenants later).

How to verify: read the ADR; confirm it matches your locked decisions (mid-market, shared DB default, seam preserved). Approve the ADR status. Downstream: ERD and openapi reflect these rules.
