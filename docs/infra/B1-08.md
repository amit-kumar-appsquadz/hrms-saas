## CI structure (`.github/workflows/ci.yml`)

`permissions: contents: read` (least privilege). No cloud calls anywhere.

Jobs (parallel):
1. **secret-scan** — `gitleaks/gitleaks-action@v2` over full history (`fetch-depth: 0`), using `.gitleaks.toml`. Artifact upload disabled so a matched value never leaks into logs/artifacts.

## How the OpenAPI drift check works

`openapi.yaml` is the single source of truth (steering rule 1), but the frontend
ships a **hand-mirrored** client (`frontend/src/types/api.ts`) because a type
generator is not wired yet. A hand mirror silently rots when the contract
changes. The check (deterministic, zero npm deps, no network) fails CI on:

1. **Surface drift** — it extracts the contract's public surface (sorted path
   list, HTTP operations, component schema names, and the members of
   security-critical enums `TenantStatus`, `PlatformRole`, and the inline
   employee-status enum), SHA-256s it, and compares to
   `.github/openapi-contract.lock.json`. Any added/removed/renamed path,
   schema, or tracked enum member flips the hash → FAIL, with a field-level diff.
2. **Mirror coverage** — every schema the mirror claims (`MIRRORED_SCHEMAS`)
   must still exist in the contract, and the mirror file must still declare its
   core shapes (not be emptied out).
3. **Admin-host guard (ADR-001/ADR-007)** — the `servers:` block may reference
   **only** the base domain and `*.app.example.com`. Any other host, or a
   literal `admin.` host, fails the check.

Re-blessing after an intentional, planner-approved contract change:
```sh
node .github/scripts/openapi-drift-check.mjs --write   # regenerate baseline
# then update frontend/src/types/api.ts to match, commit both; human reviews.
```

## How the secret scan works

`.gitleaks.toml` uses the gitleaks default ruleset (`useDefault = true`) plus a
tight allowlist. The allowlist permits ONLY the five known dev-only placeholder
strings (`hrms_local_dev_only`, `root_local_dev_only`, `mongo_local_dev_only`,
`minio_local_dev_only`, `hrms_minio_dev`) and the files that legitimately carry
dev defaults. Any other secret-shaped string anywhere still trips the scan.
Nothing real is ever allowlisted.

## Risks

- Compose bring-up and gitleaks were not executed here (no daemon / no binary);
  both are config-validated and run in CI. Verify compose bring-up once on a
  Docker host before relying on it.
- The drift check is a lightweight, purpose-built YAML surface extractor (not a
  full parser); it is intentionally strict about 2/4-space indentation matching
  the committed contract. If the contract's formatting style changes materially,
  the extractor regexes may need updating (documented in the script header).
- Pint is report-only until the skeleton is cleaned (see Known issue).
